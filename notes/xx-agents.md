# Getting Free Coding Agent Subscriptions

As a student, you have access to several powerful AI coding assistants for free. Here is how to get set up with some of the most popular ones.

## Google Gemini

Google offers models for students (Gemini 3 Pro as well as others) through the Gemini Pro plan.

1.  **Sign Up**:
    *   Go to [gemini.google/students](https://gemini.google/students/).
    *   Eligible university students can get one free year of the Gemini Pro plan.

2.  **Antigravity**:
    *   Antigravity is Google's agentic AI coding environment. You can download it at [antigravity.google](https://antigravity.google/) and use your Gemini Pro plan with it.

## Cursor

Cursor is an AI-powered code editor (forked from VS Code).

1.  **Student Plan**:
    *   Eligible university students get **one free year of Cursor Pro**.
    *   Go to [cursor.com/students](https://cursor.com/students) to sign up.
2.  **Download**:
    *   Download the editor from [cursor.com](https://cursor.com).

## Claude Code

Open a thread in Ed Discussion and ask, providing your email :) First come first served.

## GitHub Copilot

GitHub Copilot is one of the most widely used AI coding assistants. It is available for free to verified students.

1.  **Sign up for the GitHub Student Developer Pack**:
    *   Go to [education.github.com/pack](https://education.github.com/pack).
    *   Click "Sign up for Student Developer Pack".
    *   Verify your student status.
2.  **Enable & Install**:
    *   Once approved, enable Copilot in your GitHub settings.
    *   Install the GitHub Copilot extension in your IDE.
